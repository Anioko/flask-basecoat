Sidebar Component Demo

shadcn/ui inspired sidebar built with BasecoatUI + Tailwind CSS

Collapsible Sidebar

Click the toggle button in the sidebar to collapse it to an icon-only view.

Nested Navigation

Expandable groups like "Projects" and "Team" with nested sub-items.

Smooth Transitions

Animated width transitions and state persistence using localStorage.

Responsive Design

Automatically hides on mobile devices (< 768px width).

Badge Support

Show notification counts and status indicators on menu items.

User Profile

User info section in the sidebar footer with avatar and menu.

Usage Example

To use this sidebar in your templates, import the macros and define your navigation structure:

{% raw %}{% import 'macros/sidebar_macros.html' as sb %}

{% set nav_items = [
  {
    'label': 'Dashboard',
    'href': url_for('main.index'),
    'icon': '<svg>...</svg>'
  },
  {
    'label': 'Projects',
    'icon': '<svg>...</svg>',
    'children': [
      {'label': 'All Projects', 'href': '#'},
      {'label': 'Active', 'href': '#', 'badge': '8'}
    ]
  }
] %}

{% set user_data = {
  'name': current_user.full_name(),
  'email': current_user.email
} %}

{{ sb.sidebar(id='main-sidebar', items=nav_items, user=user_data) }}

{# Don't forget to include the JavaScript #}
<script src="{{ url_for('static', filename='scripts/sidebar.js') }}" defer></script>{% endraw %}
