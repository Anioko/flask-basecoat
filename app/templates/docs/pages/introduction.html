Design parity with shadcn/ui, without leaving Flask

Basecoat Docs recreate the shadcn/ui documentation experience in a Python-friendly stack. Every component is a Jinja macro imported from basecoat/index.html, so live previews, copyable markup and the pages you ship all come from the same source.
