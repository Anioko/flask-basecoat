Overview

A drag-and-drop task list component with status-based grouping. Features vertical-only dragging with smooth transforms and status management.

Features

  • Drag & Drop: Reorder tasks and move between status groups
  • Status Groups: Organize by Planned, In Progress, and Completed
  • Priority Badges: Visual indicators for task priority
  • Persistent State: Saves list state to localStorage
  • Dark Mode: Full dark mode support
  • Responsive: Adapts to all screen sizes

Interactive Demo

Usage

Drag any task to reorder within its status group or move it to a different status. Changes are automatically saved to local storage.

Feature Properties

  • Title: Feature name
  • Description: Feature details
  • Status: Planned, In Progress, or Completed
  • Owner: Person responsible
  • Priority: high, medium, or low
