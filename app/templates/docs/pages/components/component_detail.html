{% if component.name == 'checkbox' %}

Checkbox macro

{% raw %}{% from 'basecoat/checkbox.html' import checkbox %}{% endraw %} renders the shadcn checkbox (a role="checkbox" button) with its classes and data-slot attributes unchanged. Include js/checkbox.js for click and Space toggling; a name adds a hidden input so the value submits with the form.

{% from 'basecoat/checkbox.html' import checkbox %} {% from 'basecoat/label.html' import label %}
{% call checkbox(id='docs-cb-terms', name='terms') %}{{ label(content='Accept terms and conditions', for='docs-cb-terms') }}{% endcall %} {% call checkbox(id='docs-cb-mixed', indeterminate=true) %}{{ label(content='Indeterminate', for='docs-cb-mixed') }}{% endcall %} {% call checkbox(id='docs-cb-off', disabled=true) %}{{ label(content='Disabled', for='docs-cb-off') }}{% endcall %}

Arguments: name, value, checked, indeterminate, disabled, invalid, required, id, aria_label, class. A caller() block renders beside the box, normally a label whose for is the box id. Space toggles, Enter does nothing, and an indeterminate box becomes checked. See the gallery entry for every state.
