Overview

A project timeline visualization showing when tasks occur across time. Features month-based timeline with colored bars indicating task duration and department.

Features

  • Timeline View: Month-by-month visualization
  • Task Indicators: Colored dots for quick identification
  • Duration Display: Shows task length in months
  • Timeline Bars: Positioned bars showing when tasks occur
  • Responsive: Horizontal scrolling for extended timelines

View when each task occurs on the timeline. Scroll horizontally to see the full project schedule.
