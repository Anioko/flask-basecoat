Overview

A fully functional Kanban board with drag-and-drop functionality for organizing tasks across different status columns. Built with vanilla JavaScript and shadcn/ui design patterns.

Features

  • Drag & Drop: Move cards between columns with smooth animations
  • Persistent State: Saves board state to localStorage
  • Priority Indicators: Visual color-coding for task priority
  • Dark Mode: Full dark mode support
  • Responsive: Adapts to different screen sizes

Interactive Demo

Usage

Drag any card to move it between columns. The board state is automatically saved to your browser's local storage.

Card Properties

  • Title: Task name
  • Description: Task details
  • Priority: high, medium, or low
  • Assignee: Person responsible for the task
  • Due Date: Task deadline
