Before you start

This guide assumes you are integrating the docs into an existing Basecoat-enabled Flask project. Confirm the following so the experience matches ui.shadcn.com out of the gate:

  • Python 3.11 or newer with a virtual environment available for local development.
  • Node.js 18+ installed (the same runtime used by the Basecoat Tailwind pipeline).
  • pip, flask, and npm accessible from your PowerShell session.

Tip — Run pip install -r requirements-dev.txt and npm install before you begin if you are upgrading from Flask-Base. Keeping Python and Node dependencies in sync avoids asset compilation surprises later.

Install backend requirements

Create and activate a virtual environment

Keep the docs dependencies isolated from the rest of your machine by working inside a dedicated virtual environment:

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt

Sync the database (optional)

The docs themselves do not require data, but aligning your environment with the rest of the app ensures blueprints load cleanly. Apply migrations before launching the server:

flask db upgrade

Install frontend toolchain

Install Node dependencies

Basecoat Docs use PostCSS to compile Tailwind and Basecoat utilities into app/static/styles/app.css. Install the toolchain, then run a one-off build:

npm install
npm run build:css

Watch for changes

During development, keep Tailwind compiling live so updates to app/assets/styles/input.css instantly refresh your docs:

npm run watch:css

Register the docs blueprint

Mount the blueprint

The documentation blueprint lives in app/docs. Import and register it inside create_app in app/__init__.py so every page mounts under /docs:

from .docs import docs as docs_blueprint

def create_app(config_class=Config):
    app = Flask(__name__)
    app.config.from_object(config_class)

    app.register_blueprint(docs_blueprint, url_prefix="/docs")
    return app

Seed navigation

Pages are declared in app/docs/navigation.py. Add entries for every template you want to expose in the sidebar:

DOCS_NAV = [
    {
        "title": "Getting Started",
        "description": "Installation and project conventions.",
        "pages": [
            {
                "title": "Installation",
                "slug": "installation",
                "description": "Add the Basecoat docs stack to an existing Flask project.",
                "template": "docs/pages/installation.html",
            },
        ],
    },
]

Verify the docs shell

Launch the development server

Run Flask from PowerShell so the docs and the rest of your app share the same host:

$env:FLASK_APP = "manage.py"
$env:FLASK_ENV = "development"
flask run --host=0.0.0.0 --port=5100

Smoke test the experience

  • Visit http://localhost:5100/docs/installation and confirm the sidebar highlights the current page.
  • Toggle between light and dark mode and verify the theme preference persists between refreshes.
  • Update a template under app/templates/docs/pages and ensure Flask’s reloader picks up the change.
