Design tokens

The docs shell exposes CSS variables so you can retheme the experience without touching the markup. Values live under the :root selector and automatically switch when the dark theme is active.

:root {
  --docs-bg: #fafafa;
  --docs-border: rgba(15, 23, 42, 0.08);
  --docs-text: #0f172a;
  --docs-muted: #475569;
  --docs-card: #ffffff;
  --docs-code-bg: #0f172a;
}

[data-color-theme="dark"] {
  --docs-bg: #0f172a;
  --docs-border: rgba(148, 163, 184, 0.16);
  --docs-text: #e2e8f0;
  --docs-muted: #94a3b8;
  --docs-card: rgba(15, 23, 42, 0.75);
  --docs-code-bg: #020617;
}

Typography

Shadcn defaults to the Inter family. Basecoat already includes a neutral sans-serif stack, so we simply declare it on the docs shell:

body.docs-shell {
  font-family: "Inter", "SF Pro Text", ui-sans-serif, system-ui, -apple-system,
    BlinkMacSystemFont, "Segoe UI", sans-serif;
  letter-spacing: 0.01em;
}

Headers use tightened leading plus subtle tracking to match shadcn’s editorial rhythm.

Component tokens

These utilities provide a consistent feel across cards, callouts, and pagination links:

  • Radius: 0.75rem corners for page chrome, 0.5rem for callouts.
  • Shadows: 0 10px 40px rgba(15, 23, 42, 0.08) for cards in light mode, softened in dark mode.
  • Spacing: 1.25rem base padding, with vertical rhythm controlled by CSS clamp utilities.

Dark mode strategy

The theme toggle flips a data-color-theme attribute on the <html> element. All color tokens derive from that attribute, so you can adjust hues in one place without refactoring markup.
