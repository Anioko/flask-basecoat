Usage Examples

Here are some practical examples of using the input component:

Shadcn input macro

{% from 'basecoat/input.html' import input %}. Arguments: type, placeholder, value, disabled, readonly, required, invalid (sets aria-invalid), describedby, label (aria-label), class; any other keyword becomes an HTML attribute. Input has no children, so there is no caller() slot. See the gallery entry for every state.

Implementation Notes

  • Components use Basecoat CSS classes for consistent styling
  • All variants support dark mode through CSS custom properties
  • Accessibility attributes are included where appropriate
  • Components are designed to be composable and customizable
