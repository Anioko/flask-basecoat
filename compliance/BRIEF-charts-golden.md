# Brief: browser-rendered golden for the 70 shadcn charts and the `chart` example

Read `compliance/CONVENTIONS.md` first. This brief adds a second golden pipeline next to the SSR one in
`compliance/golden/render.tsx`.

## Why

Recharts' `ResponsiveContainer` measures its parent with a ResizeObserver, so under `ReactDOMServer` every chart
renders as an empty wrapper (`<div class="recharts-wrapper" style="width:0;height:0">`). The current
`compliance/golden/out/chart.html` is that empty shell and our `pages/components/chart.html` reproduces it. That is not
a chart. The oracle for charts has to be React + Recharts running in headless Chromium, with the hydrated DOM
(including the `<svg class="recharts-surface">`) saved as a static golden page that the existing checks
(`check_dom`, `check_recipes`, `check_styles`, `check_a11y`) can load unchanged.

## Inputs (all pinned, already mirrored)

- `compliance/upstream/shadcn/charts/chart-*.tsx` — the 70 charts (area 10, bar 10, line 10, pie 11, radar 14,
  radial 6, tooltip 9). They import `@/registry/new-york-v4/ui/{card,chart,select}` which `compliance/golden/tsconfig.json`
  aliases to the radix base ui (`compliance/upstream/shadcn/radix/ui`). `@/registry/new-york-v4/charts/*` is aliased too.
- `compliance/upstream/shadcn/charts-app/charts.tsx` — the grouping and which charts are `fullWidth`
  (`chart-area-interactive`, `chart-bar-interactive`, `chart-line-interactive`).
- `compliance/upstream/shadcn/charts-app/view-component-preview.tsx` — the wrapper the upstream iframe renders a chart in:
  `<div class="bg-background *:data-[slot=card]:has-[[data-slot=chart]]:shadow-none">`.
- `compliance/upstream/shadcn/radix/examples/chart-example.tsx` — the `chart` component example (six charts inside
  `ExampleWrapper`/`Example`). Its golden `out/chart.html` must be regenerated by this pipeline.
- `compliance/golden/node_modules` has react 19, react-dom 19, recharts 3.8.0, esbuild, tsx, typescript. Python has
  Playwright with Chromium (see `compliance/scripts/check_styles.py` for how it is driven).

## Canonical widths (a convention both sides share, document it in CONVENTIONS.md)

The upstream charts page is a 3-column grid; at the 1280px viewport the checks already use, one column is 384px and a
full-width chart spans 1232px. Golden and ours render a regular chart inside a 384px-wide wrapper and a full-width chart
inside a 1232px one. `ChartContainer` is `aspect-video`, so heights follow.

## Deliverables

1. `compliance/golden/charts/` with:
   - `entry.tsx`: imports all 70 chart components and `ChartExample`, reads `?name=` from the URL, renders the matching
     component with `createRoot` into `#root` inside the ComponentPreview wrapper at the canonical width. Charts also need
     `TooltipProvider`? (no, only Radix tooltip pages do; check the chart example imports). Set `window.__ready = true`
     after two animation frames once an `svg.recharts-surface` exists and its width is non-zero.
   - `build.mjs` (or an npm script): esbuild bundle, IIFE, `--define:process.env.NODE_ENV='"production"'`, tsconfig alias
     resolution, output `compliance/golden/charts/bundle.js` (ignored by git; add to `.gitignore`).
   - `harness.html`: loads `../golden.css`, sets `<html class="style-vega">`, `<body>`, `#root`, the bundle.
   - `render_charts.py`: Playwright (Python) serves the golden directory over a local `http.server` thread (file:// breaks
     module and CSS loading), opens `harness.html?name=<chart>` at viewport 1280x900, disables animations
     (`isAnimationActive` is a Recharts prop; set `window.__disableAnimation` read by entry.tsx to pass
     `isAnimationActive={false}`? No: never change upstream props. Instead wait until the DOM stops changing: poll
     `document.body.innerHTML` length/hash until stable for 300ms after `__ready`). Save
     `compliance/golden/out/charts/<name>.html` with the same document skeleton `render.tsx`'s `wrap()` uses
     (stylesheet path `../golden.css`, `data-golden="charts/<name>"`), body = the wrapper's outerHTML.
   - Hover goldens: for every chart with a `ChartTooltip`, move the mouse to the horizontal centre of the third x
     category (cartesian) or the centre of the second sector (pie/radial/radar: hover the second `.recharts-sector` /
     the second `.recharts-polar-angle-axis-tick` position) and save `<name>.hover.html` once the
     `[data-slot=chart-tooltip]`? (check the actual data-slot the radix base `chart.tsx` emits for `ChartTooltipContent`)
     is in the DOM. Record the pointer coordinates used in the manifest so `check_runtime` can replay them.
   - `manifest.json` in `out/charts/`: per chart `{group, fullWidth, width, height, slots, rechartsClasses, hover: {x, y}}`.
2. `compliance/golden/out/chart.html` regenerated through the browser (the `chart` component example, viewport 1280,
   body as the SSR goldens have it: the example wrapper directly in `<body data-golden="chart">`).
3. `compliance/golden/golden.css` rebuilt so it also scans `compliance/upstream/shadcn/charts/*.tsx` and
   `out/charts/*.html` (see how the existing build scans the examples; the Tailwind build command is in
   `compliance/golden/package.json`).
4. `compliance/scripts/extract_charts.py` — or `extract-charts.ts` with the TypeScript compiler API, your choice — that
   turns each chart TSX into a declarative JSON spec at `compliance/recipes/charts/<name>.json`:
   `{name, group, fullWidth, card: {title, description, footer: [...lines with icon names]}, chart: {type: area|bar|line|
   pie|radar|radial, data: [...], config: {key: {label, color, icon?}}, props: {margin, layout, stackOffset, startAngle,
   endAngle, innerRadius, outerRadius, barSize...}, series: [{component, dataKey, type, stackId, fill, stroke, fillOpacity,
   strokeWidth, radius, dot, activeDot, label/labelList: {...}, shape?}], axes: [{component: XAxis|YAxis|PolarAngleAxis|
   PolarRadiusAxis, props...}], grid: {component, props}, tooltip: {cursor, indicator, hideLabel, hideIndicator, nameKey,
   labelKey, formatter?: source text, labelFormatter?: source text}, legend: {...}, labels: [...Label with content]},
   interactive: {controls...}}`. Keep function props as their source text (e.g. `tickFormatter: "(value) => value.slice(0, 3)"`)
   so the runtime agent can map them to named formatters. Emit `unresolved` entries rather than guessing when a prop is a
   complex expression. Write a short `compliance/recipes/charts/README.md` describing the schema.
5. A one-page `compliance/CHARTS-GOLDEN.md`: how to rebuild, the canonical widths, what the hover golden is.

## Rules

- Never edit anything under `compliance/upstream/`. Never pass props the upstream chart does not pass.
- Python code goes through the Write tool (Bash heredocs mangle backslashes on this machine). Use absolute paths;
  the working directory resets between calls. Prefix commands with `MSYS_NO_PATHCONV=1` when an argument starts with `/`.
- Do not start or stop the local server on port 5100.
- Commit nothing. Report what you built, the exact commands to rebuild, the counts (charts rendered, hover goldens,
  specs with unresolved entries) and anything that did not work, without softening it.
